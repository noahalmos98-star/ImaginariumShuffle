Best practice tips
Automatic detection can find charaters within a full-game capture. If it misses a card or includes a false match, use the manual grid settings as a fallback.
For this to work best, make sure to keep the screenshot area tightly around the character grid (instead of a fullscreen screenshot) and enter the number of columns and rows.
Note: The number of columns and rows of the shuffled output, is always proportional to the input screenshot.
