This little HTML program runs fully locally. No files are uploaded to the internet.

I created this tool, with large help from Chat-GPT. Sorry. ^^'
It's made, in an attempt to fix some of the "problems" which I noticed during the SoulLink IT video, by Zajef77 and Zy0x.
In Imaginarium Theater, the characters are sorted by element, which I saw as potentially boring AND If your SoulLink partner has more characters available, some "fall off the edge" - making them un-selectable for your partner.

1a. You can upload a full-game screenshot, and use the auto detect feature for the program to find the character cards by itself, 
Note: This is most easily and consistently done, with Win+Shift+S and selecting the window mode in the snipping area. 
OR
1b. Create a area screenshot of your characters - making sure to keep the screenshots margins tightly around the character grid - and input the number of rows and columns manually. 
Note: If you provide a area screenshot, the auto detect feature is likely to break.

2. Change the number of characters you'd like to have output. This will create duplicates of random characters, to archive a matching length character list with your partner. Preventing some characters to "fall off".

Of course, the tool can equally be simply used to create a Randomizer of your available characters, when following a self-inflicted rule, like 
  "Use the first 4 in the list, for this encounter." 
, also helping alleviate mono-element problems which would then happen, due to the fixed ordering in IT.
